# odin-recipes

This is a basic recipe website built as part of **The Odin Project** curriculum. The goal of this project is to practice foundational **HTML skills** before moving on to styling with CSS.

##  Skills Demonstrated
* Setting up a local Git repository and linking it to GitHub.
* Structuring an HTML document with proper elements (`<html>`, `<head>`, `<body>`).
* Using headings (`<h1>` to `<h6>`) and paragraphs (`<p>`).
* Creating unordered lists (`<ul>`) and ordered lists (`<ol>`) for ingredients and steps.
* Working with hyperlinks (`<a>`) for internal page routing.
* Adding images (`<img>`) with alternative text.

##  Built With
* HTML5
* Git & GitHub

##  Project Structure
The website consists of:
* A main index page (`index.html`) with links to different recipes.
* Individual recipe pages containing ingredients and step-by-step instructions.
